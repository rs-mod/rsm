## features

<details>
<summary><b>Dungeon</b></summary>

- **SS Solver**
  - Can support high skips
- **P3 Qol**
  - Titles and Sound for: Device completed, Section Completed.
  - Show Terminal Hitboxes
- **Terminal Solver**
  - A solver for terminals
- **Leap Gui**
  - Custom Leap menu
- **Pos Msg**
  - Positional Messages
  - Optionally can work for all players in the dungeon, can play sounds and show titles.
- **Puzzles**
  - Ice Fill
  - Quiz
  - Three Weirdos
  - Tic Tac Toe
  - Teleport Maze
- **Dungeon Waypoint**
  - Waypoints for secrets and stuff
- **Abilities**
  - Ability keybinds for normal ability, and ult
- **Bar Fix**
  - Attempts to fix cross section blocks and walls state desyncing with hypixel
  - UAYOR
- **Extra Stats**
  - Runs /showextrastats at the end of a dungeon run
- **Mask/Immunity Status**
    - Tracks Spirit, Bonzo and Phoenix, renders duped masks as red, worn as gold
- **Room Secrets**
  - Shows the current rooms current / max secrets, will sync with teammates over [Odin](https://github.com/odtheking/Odin) websocket if installed.
- **Rotate Fix**
  - Fixes leap rotation being incorrect sometimes
  - Force rotates the player on boss enter
  - UAYOR
- **Secret Clicked**
  - Draws a box and plays a sound when a secret is clicked

</details>

<details>
<summary><b>Movement</b></summary>

- **Auto Sprint**
  - Acts like the sprint key is always held
- **Ether**
  - Etherwarp overlay
  - Fake Zero Ping Etherwarp/Zero Ping Teleport, (Does not actually move the player)
  - Zero Ping Interact (UAYOR)
- **Null Binds/SOCD/Snappy Tappy**
  - Like wooting keyboard behaviour, if you're holding a and press d, a unpresses until you unpress d

</details>

<details>
<summary><b>Other</b></summary>

- **Mining Event**
  - Alerts you if a specified event starts in your lobby
  - Shows a timer until a Mithril Gourmand ends and prompts you to teleport to Don Expresso
- **Powder Chest**
  - Draws boxes and tracers to powder chests in the crystal hollows
- **Sphinx Answer**
  - Answers the Mythological Ritual Sphinx question

</details>

<details>
<summary><b>Player</b></summary>

- **Key Shortcuts**
    - Bind commands to keys
- **Action Bar**
  - Hide elements from the action bar
- **Cancel Interact**
  - Cancel some item interactions
- **Chat**
  - Configurable message hiding with regex
  - Chat Emotes
- **Chest Hit Fix**
  - Allows you to interact on chests while holding left click
- **Crouch Speed**
  - Configure the players crouch animation speed
- **Equipment Helper**
  - Middle click equipment menu
  - Instant close after click
- **No Break Reset**
  - Stops item data updates from resetting breaking progress
- **No Cursor Reset**
  - Stops the cursor position from resetting between screens
  - Also stops the cursor position being incorrect after tabbing out and back into the game
- **No Place**
  - Stops unwanted placing of skulls & flowers with abilities
- **Protect Item**
  - Stops you from selling / dropping important or protected items
- **Slot Binding**
  - Allows for slots to be bound to hotbar
- **World Border Fix**
  - Stops world border preventing interactions which was not present on 1.8

</details>

<details>
<summary><b>Render</b></summary>

- **Click Gui**
  - Options for customizing RSM's Click Gui
- **Hud**
  - Time Hud
- **OpSec**
  - Name Hider/Changer
  - Server ID Hider/Changer
  - Hypixel IP Hider/Changer
- **Visual Words**
  - Replaces text visually
- **Animations**
  - Customise held item position, scaling and swing animation
- **Element Hider**
  - Hide hunger and armour bars
- **Fullbright**
  - Full bright
- **Hide**
  - Hide Players (Range, P3, Device)
  - Hide Mini Wither
  - Hide dying
- **Hide Recipe Book**
  - Hides the survival inventory recipe book
- **Image Hud**
  - Draws configurable images and GIFs on the screen
- **Jesus**
  - Jesus
- **Mana Star**
  - Shows Terraria inspired Mana stars for your Skyblock mana
- **Module List**
  - Renders a list of enabled modules
- **Tint**
  - Tints the screen a configurable colour
- **Trail**
  - Renders a trail behind you
- **Waypoints**
  - Per island & dungeon room waypoints, separate to Dungeon Waypoints

</details>
